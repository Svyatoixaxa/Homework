## Постановка задачи

Цель работы — изучить события авторизации, чтобы в дальнейшем выявлять подозрительные попытки входа и сокращать время ручной проверки журналов.

ML-задача — бинарная классификация: `0` — обычный вход, `1` — подозрительный.

## Данные

Используется файл `auth_events.csv` с 2400 учебными событиями. Данные созданы с помощью Python (`generate_data.py`), а не получены с реального сервера. В таблице указаны время входа, число неудачных попыток, использование VPN, новое устройство и необычная страна входа.

## Метрика

Выбрана метрика F2-score. Она больше учитывает полноту обнаружения, поскольку важно не пропускать подозрительные входы. Модель на этом этапе не обучается.

## Анализ данных

В файле `Задание_1_EDA_Авторизации.ipynb` проведён предварительный анализ данных (EDA): рассчитана статистика, проверены пропуски и построены графики с помощью Matplotlib и Seaborn.

Из 2400 событий 196 отмечены как подозрительные. Найдено 37 пропущенных значений. Перед обучением модели потребуется обработать пропуски и учесть дисбаланс классов.

## Запуск

Установить зависимости командой `pip install -r requirements.txt`, затем открыть ноутбук `.ipynb` в Jupyter Notebook или VS Code и выполнить ячейки.
